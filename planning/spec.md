## Open questions

- **Submission destination:** origin currently points to `GitRollTraining/ai-full-stack-it-access-requests`, not an identified personal Classroom repository. Confirm the assigned repository and default branch before pushing. The local prerequisite script only checks that a remote exists; its PASS does not resolve ownership.
- **Provider and model:** the brief requires an implemented configurable integration but does not prescribe a vendor/model. Proposed choice: OpenAI Responses API with strict structured output, selecting a supported model after checking official documentation during implementation. No live accuracy or availability is claimed at planning time.
- **Shared storage:** the brief does not prescribe infrastructure or distributed scale. Proposed choice: SQLite on one machine/local disk with multiple operator processes; multi-host/network-filesystem operation is outside this implementation's claimed support.
- **Latest revision under overlap:** export timestamps are metadata, not request facts, and the brief does not define ordering for competing batches. Proposed choice: assign durable ingestion sequence numbers transactionally; later accepted input wins, and stale workers cannot overwrite it. Explain this assumption in README.
- **Conflict and override detection:** the schema provides free-text issues, not structured flags. Define stable issue conventions in the extraction prompt and routing contract; test adversarial cases. Phrase matching alone cannot establish general prompt-injection immunity.
- **Accuracy of free text:** the brief does not prescribe normalizing purpose text, issues or quote lists. Define exact-match rules before generating outputs, report scalar and evidence/issue metrics separately, and report factual errors explicitly. Mock consistency does not measure a model's extraction quality.
- **Capture:** prerequisite check reports Entire enabled for Codex. This establishes setup, not proof that the final submitted commit has a captured session; verify that association at submission.
